# T42 UI 打磨审计与设计 token 方案

> 任务：task-42（只读审计，不改代码） · 日期：2026-11-06
> 材料：`app/src/ui/preview/*.png`（T40 后 14 张当前界面）+ qEmby MIT 参考截图（`qEmby/screenshots/2-5.png`，只参考结构/信息层级，不复制视觉）。
> 结论：整体方向正确（深色 Slate、蓝主色、卡片式内容），当前最影响观感的是**窄窗口下首页预览溢出、低对比次要文字、焦点态缺失、间距/字号 token 不统一**。以下按 P0/P1/P2 给出可执行修改点。

## 0. 审计范围与方法

- 逐页检查：首页（1280/960/1920）、媒体库、详情、季/集、播放页/控制条、设置、登录、空/错误态、播放模式自动隐藏。
- 对照 qEmby：首页 section 组织（标题 + 查看全部 + 一排海报）、详情页全宽 backdrop/标题层级、设置页左侧分类；只借鉴结构。
- 颜色对比度按 WCAG 2.x 相对亮度公式计算；文字按正常正文阈值 4.5:1（大字号 3:1）。
- 未改任何代码、未提交；本文件是唯一新增文件。

## 1. 总体问题摘要（按影响排序）

## 2. 设计 token 建议（保持现有深色主题）

### 2.1 颜色

| Token | 建议值 | 用途 | 备注 |
|---|---|---|---|
| `color.bg` | `#0B1220` | 页面底 | 现有 |
| `color.surface` | `#0F172A` | 侧栏/顶栏/分组面板 | 现有 |
| `color.surface-raised` | `#111C2E` | 卡片/输入/状态条 | 现有 |
| `color.surface-hover` | `#16233A` | hover 面板 | 现有 |
| `color.border-subtle` | `#1E293B` | 常规分隔/卡片描边 | 现有 |
| `color.border-strong` | `#334155` | hover/输入描边 | 现有 |
| `color.text-primary` | `#F8FAFC` | 标题/强调 | 17.9:1 on bg |
| `color.text-body` | `#CBD5E1` | 正文 | 12.6:1 on bg |
| `color.text-secondary` | `#94A3B8` | 次要正文/说明 | **7.3:1** on bg，6.66:1 on card |
| `color.text-muted` | **改为 `#94A3B8`** | 卡片 meta/计数/设置值 | 替代 `#64748B`；`#64748B` 3.59–3.93:1 仅用于 disabled/装饰 |
| `color.text-disabled` | `#64748B` | 禁用态 | 不用于信息性正文 |
| `color.accent` | `#3B82F6` | 主强调/焦点边 | 5.09:1 on bg；4.64:1 on card |
| `color.accent-strong` | `#2563EB` | 主按钮底 | 白字 5.17:1 |
| `color.accent-hover` | `#1D4ED8` | 主按钮 hover/nav active | 白字 6.7:1 |
| `color.focus` | `#93C5FD` | 键盘焦点环 | 10.4:1 on bg |
| `color.success` | `#34D399` | 已连接/已看 | 9.7:1 on bg |
| `color.danger` | `#FCA5A5` | 错误 | 9.9:1 on bg |

注意：`#3B82F6` 作按钮底时配白字只有 3.68:1，不满足正文 AA；主按钮继续用 `#2563EB`。`#64748B` 在 `#111C2E` 上 3.59:1，必须从「信息性 10–12px 文字」中移除。

### 2.2 间距阶梯（4/8 网格）

| Token | 值 | 典型用途 |
|---|---|---|
| `space-1` | 4px | 图标与文字、chip 内 |
| `space-2` | 8px | 按钮内上下、卡片内小间距 |
| `space-3` | 12px | 输入框内边距、卡片内主间距 |
| `space-4` | 16px | 卡片之间、行内元素 |
| `space-5` | 24px | section 之间、页面主块 |
| `space-6` | 32px | 页面左右 gutter、页面顶部 |
| `space-7` | 48px | 页面/大区块分隔（可选） |

落地建议：页面左右统一 **32px**（当前 30/34 均可归一到 32）；顶栏左右也用 32px，搜索框与页面标题左对齐；卡片 gap 统一 16px；section 间距 24px；卡片内 padding 12px。

### 2.3 字号阶梯

| Token | 字号/行高 | 字重 | 用途 |
|---|---|---|---|
| `type-display` | 28/36 | 700 | 详情标题（现 30 可降 28） |
| `type-h1` | 24/32 | 700 | 页面标题：媒体库、设置 |
| `type-h2` | 18/26 | 700 | 首页 section 标题 |
| `type-h3` | 16/24 | 600 | 详情 section「简介/剧集」、设置分组标题 |
| `type-body` | 14/22 | 400 | 正文、设置项 label |
| `type-body-sm` | 13/20 | 400/600 | 卡片标题、按钮 |
| `type-caption` | 12/18 | 400 | meta、计数、时间（最低正文尺寸） |
| `type-micro` | 11/16 | 500/600 | 仅 badge/版本号；不再用 10px 承载信息 |

原则：信息性文字不小于 12px；10px 仅限非关键装饰（版本号/角标）。标题不要同时用 16/18/22/24/30 五套。

### 2.4 圆角/卡片/图标

| Token | 值 | 用途 |
|---|---|---|
| `radius-xs` | 4px | 小 chip、进度条端 |
| `radius-sm` | 6px | 输入框内元素、episode 缩略图 |
| `radius-md` | 8px | 按钮、导航项 |
| `radius-lg` | 10px | 内容卡片、设置分组 |
| `radius-xl` | 12px | hero/backdrop 容器 |
| `radius-pill` | 999px | 状态 badge/头像 |

- 卡片统一 `radius-lg` + 1px `border-subtle`；hover 时边框 `accent`，底色 `surface-hover`。
- 海报比例：媒体库/最近添加统一 **2:3**；继续观看 **16:9**；episode 缩略图 **16:9**；详情海报 2:3。
- 首页预览卡建议：1280 宽 6 列，卡宽约 `(contentWidth - 5*16)/6`，缩略图 2:3（约 150×225）；1920 宽 8 列；960 宽 6 列时卡宽至少 96–104px，或降为 5 列（需用户确认是否允许窄屏少于 6）。
- 图标：导航 18、工具按钮 20、播放主按钮 24、标题栏 16；统一 `iconSize`，不要 18/20/24 混在一条工具栏。

### 3.7 空状态/错误态

| 级别 | 问题 | 具体建议 |
|---|---|---|
| P1 | 空状态 14px `#64748B` 对比不足；首页「暂无内容」与媒体库「暂无内容」位置/字号不一致 | 统一 EmptyState 14px `text-secondary`；page 居中/左对齐规则一致；错误用 `danger` |
| P1 | 错误文本可能是多行 API 错误，未限制宽度，长错误会撑开布局 | 设置 maximumWidth 720 + wordWrap；提供「重试」ghost 按钮 |
| P2 | 加载态与空态切换时高度变化导致跳动 | 空态容器固定最小高度 80；loading 用同一高度 |

## 7. 验收建议（实现任务时）

- 截图对比：1280×760、960×600、1920×1080；首页/媒体库/详情/设置/登录各一张。
- offscreen 断言：960 宽预览卡不超出窗口；所有可聚焦控件 `focusPolicy` 且 QSS 有 `:focus`；登录空状态 label hidden；主要文字对比度 ≥4.5:1。
- 不改变现有信息架构和 T37/T39/T40 功能；先 token/样式，再局部布局，不重写 HomeView 数据链路。

## 8. 结论

当前 UI 已是可用的深色媒体中心，主要问题不是“缺功能”，而是**尺度不统一**与**关键状态不可见**。建议先做 P0 四项（约 1.5–2 天），再按 P1 推进 token 化；P0 完成后截图观感会有明显提升，且不会影响 T39 性能优化。
