## 1. 产品目标与范围

**一句话定位**：给已有 Emby 服务器、片源含 HDR10/杜比视界/ASS 特效字幕的用户，提供一个 Windows 上"播放正确、GPU 占用低、窗口行为正常"的桌面客户端。

**核心用户价值（按优先级）**：

1. **播得对**：HDR10 不发灰、DV P5/P8 不绿屏，ASS 特效字幕按原样式显示。
2. **播得省**：硬解零回拷、渲染不经过 Qt 合成器，4K 播放时 GPU 3D 占用显著低于 qEmby。
3. **用得顺**：媒体库浏览、详情、续播、进度同步、键鼠控制、全屏；窗口可自由缩放、贴边无缝。
4. **装得上**：干净 Windows 机器安装即用，不依赖开发环境。

**MVP 范围**：单服务器、Emby 4.8/4.9、电影/剧集浏览与播放、直连播放、进度上报/续播、mpv OSC 控制条、深色 UI、安装包。

**明确不在 MVP 范围**（详见第 5 节）：弹幕、原生 HDR/DV 输出、音乐/照片/直播、离线下载、多平台。

## 2. 优先级与验收规则

| 级别 | 含义 | 发布要求 |
|---|---|---|
| **P0** | MVP 必须实现；缺一项不能发布 0.1.0 | 全部通过；任一 P0 失败 = 阻塞发布 |
| **P1** | 首个稳定版前完成；可在 MVP 后迭代 | 不阻塞 MVP；需在路线图中登记 |
| **不做** | 明确排除，避免范围蔓延 | 不实现、不承诺；如需变更走需求变更流程 |

**验收规则**：

1. 每条验收标准都必须是**可观察、可复现**的；能量化的一律给出阈值。
2. 验收环境：Windows 实机（见第 6 节）+ 真实 Emby 服务器 + S1~S8 测试素材；Linux 容器只用于编译和单元测试，**不能替代** Windows 验收。
3. 测试记录写入 `docs/test-reports/`，每条包含：操作步骤、实际结果、截图/日志、通过/失败。
4. 无法复现的"偶现"问题按失败处理，直到有稳定复现步骤并证明修复。

## 3. P0 功能需求与验收标准

### 3.1 连接与认证

| ID | 需求 | 验收标准（可测试） |
|---|---|---|
| CON-01 | 服务器地址配置与连通性检测 | 输入 `http://192.168.1.10:8096`、`https://emby.example.com/`（含尾斜杠）、`https://host/emby` 三种形式均可保存并连接；成功后 3 秒内显示 ServerName 与 Version；DNS 失败、连接超时、401、证书错误四类错误分别显示可区分的中文提示；错误后可修改 URL 重试，不重启应用。 |
| CON-02 | 用户名密码登录 | 正确凭据 3 秒内登录并进入首页；错误密码显示"用户名或密码错误"且保留已输入用户名；密码含中文、空格、特殊符号可正常登录；连续 5 次失败不崩溃；同一安装重复登录，服务端"设备"列表只新增 1 个设备（DeviceId 持久化）。 |
| CON-03 | 登录保持与退出 | 有效 token 时，关闭应用再启动 2 秒内自动进入首页；点击"退出登录"后回到登录页，本地 token 清空；服务端撤销 token 后下一次请求收到 401 时自动跳转登录页并提示"会话已过期"。 |
| CON-04 | Emby/Jellyfin 兼容探测 | `GET /System/Info/Public` 返回 ProductName 含 "Jellyfin" 时使用标准 `Authorization: MediaBrowser ...` 头；否则 Emby 使用 `X-Emby-Token`；两种服务器下 CON-01~03 均通过。 |

### 3.2 媒体库浏览

| ID | 需求 | 验收标准（可测试） |
|---|---|---|
| LIB-01 | 首页（继续观看 + 最新） | 有播放进度时显示"继续观看"横向列表，最多 20 项，按最近播放时间倒序；点击卡片 300ms 内进入详情；无进度时显示空状态提示；服务端返回 0 项不报错。 |
| LIB-02 | 媒体库海报网格 | 电影库 1000 项：首屏 1 秒内显示前 60 项；连续滚动到底无重复、无漏项，总数与服务端 TotalRecordCount 一致；1080p 下滚动帧率 ≥55fps 或无可感知卡顿；切换"电影/剧集"≤500ms。 |
| LIB-03 | 详情页（电影/剧集） | Title、ProductionYear、Runtime、Rating、Overview 与 API 一致；剧集按季分组，季数/集数与 API 一致；点"播放"从第 1 集或续播点开始；从详情返回列表保持原滚动位置（±1 项）。 |
| LIB-04 | 图片加载与缓存 | 1000 项海报异步加载，浏览中 UI 无 >200ms 冻结；二次进入同一页面 500ms 内由磁盘缓存显示；服务器断开时显示占位图不崩溃；缓存目录默认 `%LOCALAPPDATA%/emby-pc/cache/images`，上限 500MB，超限按 LRU 清理。 |

### 3.3 播放

| ID | 需求 | 验收标准（可测试） |
|---|---|---|
| PLY-01 | 播放启动（直连） | 从详情页点击播放，局域网 4K 片源 3 秒内出画面；请求 `/Videos/{id}/stream?static=true&mediaSourceId=...`，token 只在请求头、URL 中不出现；服务端 Dashboard 显示 PlayMethod=DirectPlay；测试库直连播放率 ≥80%。 |
| PLY-02 | 硬解与零回拷基线 | 播放 4K HEVC 10bit 60Mbps 10 分钟：mpv stats 的 `hwdec-current` 以 `d3d11va` 开头且不含 `-copy`；`current-vo`；GPU Copy 引擎 <2%；GPU 3D 引擎 ≤同机 qEmby 同片基线的 50%；暂停/恢复后这些值不退化。 |
| PLY-03 | HDR10 tone-map 到 SDR | Windows HDR 关闭（基准环境）：S1 HDR10 片源播放 10 分钟不发灰、不偏色，与同机 mpv CLI 参考截图肉眼无可辨差异；暗部不发灰、高光不过曝；切到桌面再切回颜色不变。Windows HDR 开启时允许系统级亮度差，但不得绿屏/紫屏。 |
| PLY-04 | 杜比视界 P5/P8 tone-map | S2（DV P5）与 S3（DV P8.1/8.4）各播放 10 分钟：无绿屏、紫屏、黑屏，人物肤色正常；三种 profile 均不崩溃；遇到不支持的 DV P7 显示可读错误或按 HDR10 基础层播放（颜色不保证），不得绿屏崩溃。 |
| PLY-05 | ASS 特效字幕 | S4 样片中位置/移动/渐变/淡入淡出/裁剪/卡拉 OK 效果与设计一致；嵌入字体正确加载（无方框、无错字体）；中英文字幕不重叠错位；开关字幕 <200ms 生效；播放 10 分钟 `frame-drop-count` ≤10。 |
| PLY-06 | 字幕/音轨切换 | OSC 字幕菜单列出全部字幕轨（含语言/标题），选择后 1 秒内生效并显示 OSD 提示；音轨菜单同理；切换后音画同步（偏差 <100ms）、进度不跳变；无音轨/无字幕轨时按钮置灰或提示。 |
| PLY-07 | 播放控制条（mpv OSC） | 鼠标移入视频区 200ms 内显示控制条，静止约 2 秒淡出；播放/暂停、上一集/下一集、进度拖动、音量、字幕、音轨、统计、全屏按钮点击均有效；1080p/4K、100%/150%/200% DPI 下布局不重叠。 |
| PLY-08 | 键盘与鼠标 | 视频焦点下：空格暂停/播放；←/→ ±5 秒；Shift+←/→ ±1 秒；↑/↓ 音量 ±5；F 全屏；Esc 退出全屏；I 统计；N/P 上下集；双击视频全屏；滚轮音量 ±2。任一文本输入框获得焦点时，空格/←→ 等不得触发播放操作。 |
| PLY-09 | 上下集与播放队列 | 剧集详情"播放整剧/播放本季"生成按 Season→Episode 升序的队列；N/P 切换 <1 秒；跨季自动进入下一季；最后一集按 N 显示"已是最后一集"且不崩溃；单集电影 N/P 置灰或提示。 |
| PLY-10 | 续播 | 服务端记录位置为 10 分钟的条目，打开后从 10:00±2 秒开始；进度 >95% 时从头开始；设置关闭"自动续播"后从头开始；续播会话只产生 1 条开始上报，不重复。 |
| PLY-11 | 播放统计 | 按 I 显示/隐藏 mpv 统计面板，至少含：分辨率、视频/音频编码、帧率、`hwdec-current`、丢帧数；全屏下同样可用；显示统计时播放不暂停，10 分钟内 `frame-drop-count` ≤10。 |
| PLY-12 | 播放错误处理 | 文件不存在、403、404、连接超时、解码失败 5 类错误：3 秒内显示可读错误（含错误码）并提供"重试/返回"；应用不崩溃；自动重试最多 2 次；重试成功后正常播放；同一错误不无限循环。 |
| PLY-13 | 全屏 | 按 F 或双击视频进入全屏 <300ms；Esc 退出并恢复进入前窗口位置/大小（±2px）；全屏时 OSC 可呼出；多显示器时在鼠标所在显示器全屏。 |

### 3.4 播放进度与会话同步

| ID | 需求 | 验收标准（可测试） |
|---|---|---|
| SYN-01 | 开始播放上报 | 开始播放后 5 秒内服务端 Dashboard 出现该会话（用户名/设备名/片名）；ItemId、MediaSourceId、PlaySessionId、CanSeek、PlayMethod 与 PlaybackInfo 响应一致；同一 Item 重复开始不产生两个并行会话。 |
| SYN-02 | 进度上报（节流） | 播放中每 10 秒（±2 秒）上报一次；暂停/恢复/拖动/切音轨/切字幕时立即上报（<2 秒）；服务端进度与客户端误差 ≤10 秒；暂停状态显示正确；连续播放 30 分钟无漏报。 |
| SYN-03 | 停止上报 | 停止播放、关闭窗口、切换剧集时 2 秒内发送 Stopped；服务端保存位置与停止时误差 ≤2 秒；下次"继续观看"使用该位置；正常关闭应用不丢最后一次进度。 |

### 3.5 窗口与系统集成

| ID | 需求 | 验收标准（可测试） |
|---|---|---|
| WIN-01 | 无边框窗口与最小尺寸 | 最终形态为无边框（原生 DWM 实现，不使用 QWindowKit）：四边可拖动改变大小；主窗口可缩至 800×480 且控件可用；播放区域可缩至 320×180；代码中不存在 900×600/960×540 的硬编码下限。 |
| WIN-02 | 贴边、最大化与 Snap | 窗口拖到屏幕上/下/左/右边缘、最大化、Win11 左右分屏：屏幕截图检查窗口最外 1px 无黑边、无桌面透出（DWM 阴影不计）；最大化后客户区 = 显示器工作区（±1px）；最大化按钮悬停出现 Snap Layouts；双击标题栏可最大化/还原。 |
| WIN-03 | 高 DPI 与多显示器 | 100%/125%/150%/200% 缩放、双屏不同 DPI：文字不模糊、控件不重叠、视频铺满；跨屏拖动后视频不黑屏/不缩小；全屏在鼠标所在屏。 |
| WIN-04 | 窗口状态恢复 | 最大化状态关闭再启动恢复最大化；普通状态关闭再启动位置/大小误差 ±2px；显示器被拔掉后启动窗口不跑到屏幕外（夹到可用工作区）。 |

### 3.6 设置、日志与诊断

| ID | 需求 | 验收标准（可测试） |
|---|---|---|
| SET-01 | 设置页 | 至少包含：服务器地址、账号、退出登录；硬件解码信息（只读显示 `hwdec-current`）；默认字幕语言；自动续播开关；音量记忆开关；日志目录"打开"按钮；关于/版本。修改后重启应用仍保持；非法 URL/数值被拒绝并提示。 |

| SET-03 | 关于与诊断 | 关于页显示应用版本、Qt 版本、libmpv 版本、构建时间；"复制诊断信息"可复制到剪贴板且不包含 token；显示当前 GPU 与 `hwdec-current`（来自 mpv）。 |

### 3.8 非功能需求

| ID | 需求 | 验收标准（可测试） |
|---|---|---|
| NFR-01 | 启动与交互性能 | 冷启动到主窗口可交互 ≤3 秒（SSD、已登录）；媒体库首屏 ≤1.5 秒（有缓存）；页面切换 ≤300ms；播放中 UI 线程无 >200ms 阻塞。 |
| NFR-02 | 播放性能与资源 | 4K HEVC 10bit 24fps 连续播放 2 小时：GPU 3D ≤15%（参考机 RTX 3060 级）、Copy <2%、Video Decode 有负载；CPU ≤25%；无持续丢帧（`frame-drop-count` ≤20）。 |
| NFR-03 | 稳定性 | 连续播放 8 小时不崩溃、不黑屏；快速切集 100 次无崩溃；8 小时后内存 RSS 增长 ≤10% 或 ≤100MB；退出后无残留进程与句柄泄漏（Process Explorer 检查）。 |
| NFR-04 | 兼容性 | Windows 10 21H2/22H2、Windows 11 22H2/23H2 x64 均可安装运行；Emby 4.8.x/4.9.x 通过全部 P0；NVIDIA 与 Intel/AMD 至少 2 个 GPU 厂商的适配器（同一台机器的独显+集显也可）通过 PLY-02；不支持 `d3d11va` 的机器自动降级 `auto-safe` 并提示，不崩溃。 |
| NFR-05 | 安全 | token 不出现在任何 URL、日志、崩溃转储的明文中；TLS 证书默认校验，自签证书需用户显式信任并记录指纹；QSettings 文件权限仅当前用户可读；密码不落盘。 |
| NFR-06 | 国际化 | 全部用户可见字符串经 `tr()`；简体中文界面无英文残留（品牌名、编码名、格式名除外）；字符串缺失时回退中文不崩溃。 |
| NFR-07 | 构建可复现 | `scripts/build-linux.sh` 在干净 Linux 容器一条命令完成配置+编译；Windows 构建步骤文档化，按文档在干净机器可复现；构建产物版本号一致。 |

## 4. P1 功能清单（MVP 后迭代）

| ID | 功能 | 验收标准（简版） |
|---|---|---|
| P1-01 | 全局搜索 | 输入 ≥2 字符 500ms 内返回电影/剧集/集结果；空结果显示提示；清空恢复初始列表。 |
| P1-02 | 服务端转码 fallback（HLS） | 对强制转码条目 5 秒内起播；可切换码率/分辨率；拖动进度可用；切回直连时无残留。 |
| P1-03 | 自动连播与跳过片头 | 片尾前 10 秒 OSD 倒计时，可取消；播完自动下一集；有章节/媒体段标记时"跳过片头"误差 ±2 秒。 |
| P1-04 | 音频直通开关 | 设置开启后 AC3/EAC3/DTS/TrueHD 可直通到功放；不支持时自动回退 PCM 并 OSD 提示；无爆音、无持续无声。 |
| P1-05 | 字幕样式与在线字幕 | 字号 50%~200%、颜色、描边、底部偏移可调并记忆；支持加载外挂字幕；在线字幕搜索（可选）失败不影响播放。 |
| P1-06 | 播放速度、A-B 循环、截图 | 0.5~2.0 倍速带音调校正；A-B 循环设置/清除正确；截图保存 PNG 到图片目录并提示路径。 |
| P1-07 | 多服务器/多用户 | 可添加/切换多个服务器，各自 token 隔离；切换后媒体库/续播数据正确不串。 |

| P1-09 | 自动更新与崩溃上报 | 检查新版本、下载、校验安装；崩溃日志可选上传（默认关闭）；更新失败可回退旧版本。 |

## 5. 明确不做（Non-goals）

| 项 | 原因/替代方案 |
|---|---|
| **弹幕** | 产品决定不做；无弹幕渲染/叠加代码。 |
| **原生 HDR/DV 输出、HDR 检测与提示** | decisions v3 已确认：只要求 tone-map 到 SDR 不发灰；不检测系统 HDR，不做 HDR swapchain/元数据输出。 |
| **杜比视界 P7 原生支持** | mpv 0.41 不覆盖 P7 双层；按 HDR10 基础层处理，颜色不保证；不承诺点亮。 |
| **音乐、照片、直播 TV、录像** | MVP 只做电影/剧集点播。 |
| **离线下载/缓存整集** | 涉及断点续传、授权与缓存管理，非 MVP 核心；P1 之后再评估。 |
| **服务端管理（用户/库/转码设置）** | 客户端只消费 Emby API，不做管理后台。 |
| **跨平台（macOS/Linux）** | MVP 只做 Windows；架构预留 `IVideoSurface` 接口，未来再说。 |
| **自研解码/渲染/播放引擎** | 用 libmpv；不在本项目重写 FFmpeg/D3D11 渲染器。 |
| **皮肤/插件系统、浅色主题** | 只做深色，减少 UI 成本。 |
| **投屏/DLNA/远程控制** | 非核心场景，不做。 |
| **移动端/Web 端** | 只做 Windows 桌面。 |
| **广告、遥测、用户数据上报** | 无遥测；只保留本地日志与崩溃 dump。 |

### 6.3 测量工具与判据

| 验收项 | 工具 | 通过判据 |
|---|---|---|
| 硬解/渲染路径 | mpv stats（I 键）：`hwdec-current`、`current-vo` | `d3d11va` 且无 `-copy`；`gpu-next` |
| GPU 占用 | 任务管理器 GPU 引擎 / PresentMon | 3D ≤ qEmby 基线 50%；Copy <2% |
| HDR/DV 颜色 | 同机 mpv CLI 参考截图 + 人工目检 + 截图归档 | 不灰、不绿、不紫、肤色正常 |
| 字幕/特效 | 目检 + `frame-drop-count` | 样式正确；10 分钟丢帧 ≤10 |
| 窗口缝隙 | 屏幕截图 + 像素检查脚本 | 最外 1px 无黑边/透底 |
| Emby 上报 | 服务端 Dashboard + API 响应 | 进度误差 ≤10 秒；停止误差 ≤2 秒 |
| 内存/句柄 | Process Explorer / VMMap | 8 小时增长 ≤10% 或 ≤100MB |
| 网络/URL 安全 | 抓包 + 日志文本搜索 | URL 无 token；日志无 Authorization |

### 6.4 冒烟测试（每次发布前 15 分钟）

1. 干净机安装 → 启动 → 登录 → 首页显示。
2. 播放 S5 → 暂停/继续 → 拖动 → 停止。
3. 播放 S1/S2/S3 各 2 分钟 → 目检不灰/不绿。
4. 播放 S4 → 字幕显示 → 切字幕/音轨。
5. 全屏进出 → Esc 恢复。
6. 关窗 → 重启 → 续播位置正确。
7. 检查日志无 token/密码。
